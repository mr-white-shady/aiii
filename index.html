PROGRAM 5 – Rule-Based Expert System

Aim:

To write a Python program to implement a simple rule-based medical expert system that identifies a possible condition from the symptoms entered by the user.

Algorithm:

  1. Start the program.
  2. Read the symptoms (fever, cough, cold, headache) from the user as yes/no.
  3. If fever and cough are both yes, display "Flu".
  4. Else if fever and headache are both yes, display "Viral Fever".
  5. Else if cold and cough are both yes, display "Common Cold".
  6. Else if headache is yes, display "Headache".
  7. Otherwise, display "Condition could not be determined".
  8. Stop the program.

Program:

# Simple Medical Expert System
print("MEDICAL EXPERT SYSTEM")
print("---------------------")

fever = input("Do you have fever? (yes/no): ")
cough = input("Do you have cough? (yes/no): ")
cold = input("Do you have cold? (yes/no): ")
headache = input("Do you have headache? (yes/no): ")

if fever == "yes" and cough == "yes":
    print("Possible condition: Flu")
elif fever == "yes" and headache == "yes":
    print("Possible condition: Viral Fever")
elif cold == "yes" and cough == "yes":
    print("Possible condition: Common Cold")
elif headache == "yes":
    print("Possible condition: Headache")
else:
    print("Condition could not be determined.")

Output:

---------------------
Do you have fever? (yes/no): yes
Do you have cough? (yes/no): yes
Do you have cold? (yes/no): no
Do you have headache? (yes/no): no
Possible condition: Flu

PROGRAM 7 – Data Preprocessing Using Pandas

Aim:

To write a Python program to preprocess a dataset using Pandas by handling missing values and removing duplicate rows.

Algorithm:

  1. Start the program.
  2. Import the pandas library.
  3. Create a sample dataset (Name, Age, Marks) with some missing values and convert it into a DataFrame.
  4. Display the original data.
  5. Count and display the missing values in each column.
  6. Fill the missing values of Age and Marks with their column mean.
  7. Display the data after preprocessing.
  8. Remove the duplicate rows.
  9. Save the cleaned data into a CSV file.
  10. Stop the program.

Program:

import pandas as pd

# Create sample dataset
data = {
    'Name': ['Arun', 'Bala', 'Cathy', 'David', 'Eva'],
    'Age': [20, 21, None, 22, 20],
    'Marks': [85, 90, 78, None, 88]
}

df = pd.DataFrame(data)
print("Original Data:")
print(df)

# Check missing values
print("\nMissing Values:")
print(df.isnull().sum())

# Fill missing values
df['Age'] = df['Age'].fillna(df['Age'].mean())
df['Marks'] = df['Marks'].fillna(df['Marks'].mean())

print("\nAfter Preprocessing:")
print(df)

# Remove duplicate rows
df = df.drop_duplicates()

# Save cleaned data
df.to_csv("cleaned_students.csv", index=False)
print("\nCleaned data saved successfully.")

PROGRAM 8 – NLP: Text Tokenization and Word Frequency

Aim:

To write a Python program to perform text tokenization and find the frequency of each word using NLTK.

Algorithm:

  1. Start the program.
  2. Import nltk, word_tokenize and Counter, and download the required tokenizer data.
  3. Store the input text in a variable.
  4. Convert the text to lowercase.
  5. Split the text into tokens (words) using word_tokenize().
  6. Remove punctuation by keeping only alphabetic tokens.
  7. Display the tokens.
  8. Count the frequency of each word using Counter.
  9. Display each word with its count.
  10. Stop the program.

Program:

import nltk
from nltk.tokenize import word_tokenize
from collections import Counter

nltk.download('punkt')
nltk.download('punkt_tab')

text = "Artificial intelligence is powerful. Artificial intelligence is useful."

# Convert to lowercase
text = text.lower()

# Tokenization
words = word_tokenize(text)

# Select words only
words = [word for word in words if word.isalpha()]

print("Tokens:")
print(words)

# Word frequency
frequency = Counter(words)

print("\nWord Frequency:")
for word, count in frequency.items():
    print(word, ":", count)

Output:

Tokens:
['artificial', 'intelligence', 'is', 'powerful', 'artificial', 'intelligence', 'is', 'useful']

Word Frequency:

intelligence : 2
is : 2
powerful : 1
useful : 1

PROGRAM 9 – Naive Bayes Classifier (Spam / Not Spam)

Aim:

To write a Python program to classify a text message as Spam or Not Spam using the Naive Bayes classifier.

Algorithm:

  1. Start the program.
  2. Import CountVectorizer and MultinomialNB from scikit-learn.
  3. Create the training messages and their labels (Spam / Not Spam).
  4. Convert the text messages into numerical form using CountVectorizer.
  5. Create the Naive Bayes model and train it using fit().
  6. Take a test message and convert it using the same vectorizer.
  7. Predict the class of the test message using predict().
  8. Display the message and its prediction.
  9. Stop the program.

Program:

from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB

# Training data
messages = [
    "win money now",
    "free lottery ticket",
    "claim your prize",
    "meeting at 10 am",
    "project meeting tomorrow",
    "submit the assignment"
]

labels = [
    "Spam",
    "Spam",
    "Spam",
    "Not Spam",
    "Not Spam",
    "Not Spam"
]

# Convert text into numbers
vectorizer = CountVectorizer()
X = vectorizer.fit_transform(messages)

# Train Naive Bayes classifier
model = MultinomialNB()
model.fit(X, labels)

# Test message
test_message = ["free money prize"]
test_X = vectorizer.transform(test_message)
prediction = model.predict(test_X)

print("Message:", test_message[0])
print("Prediction:", prediction[0])

Output:

Message: free money prize
Prediction: Spam
